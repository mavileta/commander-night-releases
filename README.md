# Commander Night — descargas

*English below.*

Commander Night es un programa para jugar partidas de Commander de 2 a 10
jugadores: contra bots, en red, con cartas digitales, con tus cartas físicas
ante una cámara o mezclando las dos cosas. Este repositorio solo contiene
las versiones publicadas y los documentos para quien las usa.

## Descargar

En [Releases](../../releases/latest), la última versión:

- **Windows:** `Commander Night_<versión>_x64-setup.exe`. No está firmado:
  la primera vez SmartScreen avisa; pulsa «Más información» → «Ejecutar de
  todas formas». Después se actualiza solo.
- **macOS:** el `.dmg`. Sin firmar: la primera vez, clic derecho sobre la
  app → «Abrir».
- **Android** (cámara para tu sitio en la mesa):
  `commander-night-camara_<versión>.apk`.

# Commander Night — downloads

Commander Night is a program for playing Commander games with 2 to 10
players: against bots, online, with digital cards, with your physical cards
in front of a camera, or a mix of both. This repository only holds the
published versions and the documents for its users.

Get the latest version from [Releases](../../releases/latest): the Windows
installer (unsigned: SmartScreen warns the first time, “More info” → “Run
anyway”), the macOS `.dmg` (unsigned: right-click the app → “Open” the first
time) and the Android camera app `.apk`. Questions or bugs: open an issue.
